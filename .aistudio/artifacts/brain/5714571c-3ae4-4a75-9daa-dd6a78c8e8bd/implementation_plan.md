# 實作計畫：網站存取密碼驗證登入頁（預設密碼 8888）

為保護年表資料與提供專屬存取體驗，在進入年表主站前增加一層典雅設計的登入驗證頁（預設密碼 `8888`），並根據用戶確認之偏好設置會話管理機制。

---

## 用戶需求與確認規格

1. **存取密碼**：預設為 `8888`。
2. **驗證保存機制**：採用 `sessionStorage` 儲存驗證標記，當使用者**關閉分頁或瀏覽器後自動重置**，下次開啟時需重新輸入。重新整理（F5 / Refresh）當前分頁時保留登入狀態，無需重複輸入。
3. **主站介面**：進入主站後**無需登出或重新鎖定按鈕**，驗證成功後享有完整不間斷的瀏覽體驗。
4. **視覺風格**：延續歷史博物館/文史典藏的深色奢華金石風格（相容深淺色主題切換），呈現莊嚴典雅的門戶鎖定意象。

---

## 規劃變更內容

### 1. 新增登入驗證門戶元件 `src/components/LoginGate.tsx`
- **門戶視覺設計**：
  - 中央典雅卡片：深色黑曜石/石板灰搭配金黃色古銅微光邊框 (`amber-500/20`、`border-amber-500/30`)。
  - 圖標與標題：徽章鎖定圖示、中文主標題「世界文明對照年表」、副標題「世界歷史大事結構化時間軸資料庫 · 系統安全存取驗證」。
  - 密碼輸入框：
    - 支援文字/密碼隱藏切換（`Eye` / `EyeOff` 圖標）。
    - 佔位提示文字「請輸入存取密碼」。
    - 支援 Enter 鍵快速提交。
    - 載入時自動聚焦 (`autoFocus`)。
    - 輸入框排斥 `user-select: none`，確保可正常輸入。
  - 錯誤回饋：密碼不符時觸發震動動畫（Shake effect）並顯示「密碼不正確，請重新輸入」溫馨提示。
  - 主題同步：右上角保留深淺色模式切換按鈕，方便使用者隨時切換。
- **解鎖行為**：
  - 輸入值與 `8888` 匹配時，寫入 `sessionStorage.setItem('chronology_auth_unlocked', '1')`。
  - 觸發 `onSuccess` 回調，平滑過渡進入年表主系統。

### 2. 整合至入口 `src/App.tsx`
- 初始化狀態：
  ```tsx
  const [isAuthenticated, setIsAuthenticated] = useState<boolean>(() => {
    try {
      return sessionStorage.getItem('chronology_auth_unlocked') === '1';
    } catch {
      return false;
    }
  });
  ```
- 條件渲染：
  - 當 `!isAuthenticated` 時，優先渲染 `<LoginGate onAuthenticated={() => setIsAuthenticated(true)} theme={theme} onToggleTheme={toggleTheme} />`。
  - 當 `isAuthenticated` 為真時，渲染完整的年表主程式（保留既有之表格/時間軸/防複製/版權聲明等完整功能）。

---

## 驗證計畫

1. **密碼驗證正確性**：
   - 輸入錯誤密碼（如 `1234`、`0000`）：出現紅字錯誤提示與輸入框晃動，不允許進入。
   - 輸入正確密碼（`8888`）：成功驗證並解鎖進入世界文明對照年表主頁。
2. **會話持久性驗證**：
   - 登入後按 F5 重新整理分頁：保持已登入狀態，不需重複輸入。
   - 關閉分頁或新開無痕分頁：需重新輸入 `8888`。
3. **防複製與快捷鍵相容性**：
   - 確保在登入頁輸入密碼時鍵盤操作正常，不會受到全域防複製監聽干擾。
4. **編譯與型別檢查**：
   - 執行 `compile_applet` 確保 0 錯誤順利建置。
